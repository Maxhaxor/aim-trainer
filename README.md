# Aim Trainer — Dust Arena

Multiplayer aim trainer with:
- Dust-style map (walls, crates, pillars)
- Usernames + nametags
- Headshot instakill + body damage
- CS-style kill feed
- Distant spawn points
- Procedural headshot sound (original Web Audio — not Valve assets)

Play: https://aim-trainer-phi-five.vercel.app/

Controls: WASD, Space, RMB scope, LMB shoot, 1/2 weapons, enter name on menu.
